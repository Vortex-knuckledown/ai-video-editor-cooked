# Motify motion doctrine (vendored, Apache-2.0)

Reference only. Read the file that fits:

- `motion-language.md`: the move vocabulary, the four doctrine rules (smooth over bouncy; reveal on the spoken word
  across the back half; no breathing, no bad push; velocity-matched seams) and the seek-safe rules.
- `cut-catalog.md`: the cuts built inside a scene (zoom-through, cut-the-curve, waterfall) and when to use each.
- `cut-the-curve.md` and `cut-the-curve-gsap.md`: the seam in full, with GSAP templates and numbers.
- `seam-gate.md`: how a seam is measured (an exit that has settled or an entry that starts from rest fails).
